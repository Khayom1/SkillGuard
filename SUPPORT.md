# Support

## Getting help

- **Documentation**: Start with the [README](README.md), [Threat Model](docs/THREAT_MODEL.md), [Architecture](docs/architecture.md), and [Detection Rules](docs/rules.md).
- **Bug reports**: Open a GitHub Issue using the bug report template. Include the SkillGuard version, Node.js version, operating system, the exact command run, and a minimal reproduction when possible.
- **Feature requests / design questions**: Open a GitHub Issue or Discussion. Describe the problem, the desired outcome, and any constraints (especially privacy or offline requirements).
- **Security vulnerabilities**: Do **not** open a public issue. Follow the process in [SECURITY.md](SECURITY.md).

## What we can and cannot help with

SkillGuard is an offline static analyzer. We can help with:

- Understanding findings and rule intent
- Configuration, CLI behavior, GitHub Action usage, and integrity locks
- False positives that appear systematic
- Documentation gaps

We cannot:

- Certify that a skill is safe
- Debug or remediate third-party agent runtimes
- Review private skill content unless you explicitly share it in a controlled manner
- Provide legal or compliance advice

## Response expectations

This is an independently maintained project. Response times vary. Security reports receive priority.
